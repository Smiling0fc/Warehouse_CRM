# Контур склада — Warehouse_CRM

Функциональный каркас CRM склада. Демонстрационные данные, дата среза 03.10.2026. Реальных подключений к базам, авторизации и Claude пока нет.

## Сайт

GitHub Pages публикует корень ветки `main`. Маршруты используют hash: `#/inventory`, поэтому перезагрузка страницы работает без серверного роутинга. Все ресурсы локальные и подключены относительными путями; CDN и сборка не требуются.

## Возможности

- Dashboard: направление, день / 7 дней / 1 месяц / 1 год, тренды, график приёмки и отгрузки, очереди и загрузка.
- Остатки: поиск, доступное количество, резерв, проверка, CSV.
- Приёмка: фактическое количество, исполнитель, расхождения; остаток, место и начисление меняются согласованно.
- Грузовые места: расположение, перемещение, история.
- Команда: выработка, базовая/сдельная оплата, расшифровка, CSV.
- Финансы: начисления, расходы, результат, задолженности, новый расход.
- Калькулятор пополнения и локальный демо-разбор показателей вместо неподключённого Claude.
- Сохранение демо-операций в браузере, сброс в настройках.

## Архитектура и перенос

Модули расположены в корне для прямой публикации на GitHub Pages:

| Файл | Назначение |
|---|---|
| index.html, styles.css | Оболочка и адаптивные стили |
| app.js | Экраны и обработчики |
| icons.js | Иконки |
| seed.js | Вымышленные исходные данные |
| domain.js | Правила операций и расчёты |
| repository.js | DemoRepository и HttpRepository |
| config.js | Runtime-конфигурация без секретов |
| domain.test.mjs | Проверки бизнес-правил |

Интерфейс работает через repository: snapshot и команды. Подготовленный HTTP-адаптер подключается к будущему backend. Реальные права, транзакции, интеграции, ключ Claude и общая база должны работать на сервере. Переключение config.js не заменяет разработку backend.

## Запуск и тесты

```sh
python3 -m http.server 8080
# Открыть http://localhost:8080
node --test domain.test.mjs
```

Для тестов нужен Node.js 22+. Установка зависимостей не требуется. Через file:// ES-модули не запускаются.

## Публикация

Settings → Pages → Deploy from a branch → main → / (root). После commit GitHub обновляет сайт. Новые секреты и реальные данные склада в публичный репозиторий не добавлять.

Все суммы, документы, тарифы и сотрудники тестовые. LocalStorage не является общим или защищённым хранилищем. В производственном режиме переносится frontend и разворачивается совместимый backend — см. MIGRATION.md.
