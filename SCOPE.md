# Объём v0.1

Подготовлен функциональный каркас для просмотра и проверки сценариев, не промышленная CRM.

## Реализовано

Девять экранов: обзор, остатки, приёмка, места, команда, финансы, планирование, помощник, настройки. Фильтрация направлений/периода; поиск остатков; приёмка одного SKU на документ; агрегированное место на приёмку; запись перемещения; начисления сотрудникам; добавление расхода; CSV; локальный демо-разбор; калькулятор пополнения.

## Явные ограничения

- Все цифры и сотрудники вымышлены. Из контекста проекта взяты названия направлений, общая площадь и структура команды (10 + 15).
- Фиксированная демо-дата 03.10.2026, история 14 дней для сравнения двух недель. Дата фактического действия в аудите — текущее время браузера. Выплаты рассчитываются за демо-период.
- Грузовые места представляют неполный демонстрационный набор: они не раскладывают весь складской остаток. Одна демо-приёмка создаёт одно агрегированное место даже при нескольких заявленных коробах. В промышленной версии нужен пересчёт по строкам и отдельным коробам.
- Не реализованы частичная приёмка, завершение разбирательства по расхождению, отгрузки через UI, редактирование тарифов, разделение/объединение мест, проверка брака, производство по спецификациям, закрытие смен и реальные сканеры.
- Поля локаций свободные. Серверная версия должна проверять ячейки по справочнику.
- Выработка в демо считается за завершённые смены 8 часов; это не live-рейтинг производительности.
- Оплата труда предварительная; нет реальных налогов и взносов. Рост начисленной зарплаты отображается как рост затрат, а не оценка эффективности сотрудника.
- Доходы и базовые расходы — демо-журнал; начисления хранения по истории ещё не реализованы. Площадь статична и не обновляется при перемещении.
- Кредиторка/дебиторка демонстрационные, без банковских оплат; они не повторно вычитаются из прибыли.
- Реального Claude нет. Ответы локальные и явно помечены, произвольный запрос не имитирует подключение к модели.
- Интерфейс не содержит входа или защиты данных. GitHub Pages используется для публичного демо с вымышленными данными.
- В localStorage отсутствуют транзакции нескольких сотрудников; права/идемпотентность/аудит должны обеспечиваться сервером.
